# AC1 魏、蜀技能域复核

基线 `849c368`，本轮按武将目录的印刷 `camp` 划分，覆盖标准、风、火、林、山与 SP；神将即使开局选择魏/蜀仍属于神将域。读取 CLAUDE、AC 路线图、AA/AB 验收、技能原文所在完整武将卡、既有规格和真实引擎实现后提出候选；没有以旧测试全绿代替审计。

目录现算：36 张非神魏/蜀武将牌，63 个原生技能槽，其中53个已实现槽、10个未实现槽；已实现原生唯一 ID 为51个。重复槽为普通/SP关羽的武圣、马超/SP庞德的马术。本域另复核凿险派生急袭，因此下表有52个唯一技能行。林包在目录中的 pack 值为 `forest`，山包为 `mountain`。

## 方法和来源边界

原文路径均相对 `official-skill-cache/gltjk-sanguosha-rules/pages/`；表中 `wei`、`shu` 指 `card__hero__wei.md`、`card__hero__shu.md`。标准与风 fixture 有部分历史人工摘要，不能用摘要覆盖明确的规则正文；火/林/山/SP已带逐行 `sourceLine`。每行同时核对同一武将的整个技能集，拒绝把界限突破、1V1额外技能或旧/新风不同武将牌的单行技能拼起来。

源码主域为 `src/engine/skills.js`；表中 `state`、`game`、`tricks`、`sha` 分别指同目录 `state.js`、`game-engine.js`、`tricks.js`、`sha-flow.js`。测试名称均为 `tests/` 下文件。表中“既有”表示本次阅读了相应断言和对应实现，不等于本轮重新为每条技能编造一个镜像测试。“新 WS/WF/AA”指 `v16_ac_wei_shu_audit.test.mjs` 的真实公开API回归。挂起场景核对实体牌守恒，主动使用路径与打出响应路径分开。

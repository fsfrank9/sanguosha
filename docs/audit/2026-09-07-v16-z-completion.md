## Z-G1：木牛流马边界裁定

**本批不加入木牛流马**，C9 按“边界未开启，不实施”记录。
依据是 `card__equipment.md:151` 明确列为“界限突破·宝物”，`:153` 新增

附属牌移动语义。这会增加宝物装备槽、牌区和第 40 个牌型，属于内容边界

用户本轮授权一次完成 Z；按 Z3 原定“默认不做，边界另行点单”的条件执行。
本裁定不阻塞 Z1 / Z2 / Z4，也不以扩目录替代既定内容修复。

## 验证可信度修正

本轮发现 `v15_w_conservation_soak.test.mjs` 读取不存在的 `census.total`
和 `census.byZone`，导致其计数比较实际是 `undefined === undefined`。
此前该测试通过能证明对局推进未报错，不能证明该项计数校验有效；其他使用
`assertCardConservation` 的逐例守恒断言不受此问题影响。

本批改为逐步比较开局与当前的完整实体牌 ID 集合，并检查重复占区。
这样同数量的“丢一张又多一张”也会失败。原 Y 合并基线使用修正后的检查
实跑 600 种子通过；Z 最终验证另将两名 SP 武将加入压力测试池。
压力测试的玩家决策表同时补上庸肆的多张 `cardIds` 成本，按窗口数量选择
公开候选；原单牌兜底不能回答必选的多牌窗口，没有改动引擎的强制弃牌规则。

## 交付与最终验收

- Z1：单骑、庸肆、伪帝接入；SP fixture/cache、技能元数据、图鉴同时翻转。
  伪帝覆盖现有九种主公技，黄天/制霸对不同持有者分别计次；庸肆按手牌和
  装备支付成本，并与枭姬、固政、普通手牌上限结算衔接。
- Z2：巧变补全出牌阶段分支，成本与移动分开处理，选择面绑定窗口对象身份。
  校验空装备槽、重复判定牌、谦逊/帷幕和转化身份；允许仅付费跳过，旧山包
  fixture/cache 与审计的功能缺口同批清除。
- Z4：轻伤且无弃牌及未覆盖来杀压力时保留最后一桃，额外桃、低血、多伤
  及庸肆必弃面仍可回血；同一桃也有转化候选时，保留回血与转化的原有比较。
  拼点双方扣置后、亮牌前提交失牌效果，统一帧保存逐席进度；认领、暂停、
  JSON 克隆续跑和终局收尾均保持守恒，不重复触发失牌。
  濒死后的伤害上下文不再保存指向 game 的循环引用，续跑时绑定当前局。

独立 Codex 代理根据官方源和端到端反例复核；未使用当前环境未提供的 opus。
复核促成修复：庸肆误弃保留桃、固政遗漏装备、伪帝双接收者配额、暴虐势力
采样、拼点连营摸桃晚于驱虎救援。全档另抓到轻伤关羽被强迫武圣转化、黄天
AI 对伪帝持有者读取暗身份两条问题，均补行为回归。实际屯田测试覆盖亮牌前
判定与自动改判；连续失牌挂起测试采用协议注入，不声称屯田新增人工改判窗。

Q2 基准曾因只按血线强制留桃而失败（两档内奸均 0 胜）。隔离消融确认是
C23 新增门的影响：有可达敌人、自身无闪仍留桃，忽略已有战斗压力估计。
最终复用 `aiEvaluateStateWithThreat` 的公开/感知来杀量与自身响应牌计算，
有未覆盖攻击压力就放回正常回血候选。无武将、种子或内奸 profile 特例，
原 Q2 测试文件、固定样本与门槛未改；新增有闪/无闪、龙胆和同牌池暗牌互换
的实际行动对照。此为保守战斗压力判断，不承诺预测所有拆牌/突袭收益。

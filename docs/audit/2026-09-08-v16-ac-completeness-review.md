## 独立发现：挑衅装备转化失败仍领取失装收益

| 项目 | 复核结果 |
|---|---|
| 被审修改 | 魏蜀作者在 `src/engine/skills.js` 的 `playTiaoxinSha` 为挑衅增加武圣／龙胆转换；最初先调用有副作用的 `findResponseCard`，随后才调用 `playSha` 校验目标 |
| 来源 | 本地规则镜像 `card__hero__shu.md:354` 要求使用【杀】；`glossary__card.md:49–52` 明确举出武圣把装备区武器当【杀】响应时，不能选择必须依赖该武器范围才够到的角色 |
| 实际反例 | 五座席，关羽获得枭姬，唯一红色青釭剑提供范围 2；距离 2 的姜维挑衅。提交武器 ID 后，【杀】返回距离不足，但枭姬已摸两张，武器又被回滚到装备区，选择窗口仍在，可重复获得收益 |
| 失败证据 | 新回归初次执行 `1/1` 失败：拒绝动作后手牌期望 0，实际 2；牌守恒仍成立，说明单看守恒不能发现非法收益 |
| 修复复核 | 原作者在真正取牌前建立只读扣除材料的状态预览，校验距离和目标保护；AI 继续尝试后续合法材料。审查者未修改其生产函数 |
| 修后证据 | 同一回归连续两次提交该无效 ID 都失败，手牌 0、牌堆 30、武器仍在原处、目标体力不变；原魏蜀合法手牌及装备转换回归继续通过 |

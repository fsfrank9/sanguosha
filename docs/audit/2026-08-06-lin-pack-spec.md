## 版本变体裁定

本仓同时支持 1v1 与 3/4/5 人身份场, **一律取通用版 (林)**; 分歧记档如下。

| 技能 | 变体 | 分歧 | 裁定 |
|------|------|------|------|
| 断粮 | 1V1 (`wei.md:281`) | 只保留"黑色牌当兵粮寸断", **删掉了"距离为2"那半句** (1v1 只有对手, 距离恒 1, 该半句无意义) | 取通用版; 1v1 中距离放宽自然惰性, 两版行为等价 |
| 帷幕 | 国-标 (`neutral.md:217`) | "每当你**成为**黑色锦囊牌的目标时，你**取消自己**" —— 与林版"你**不是**黑色锦囊牌的**合法目标**"**语义不同**: 前者仍成为目标再取消 (可被"成为目标时"的时机看到), 后者根本不能被指定 | **取林版 (不是合法目标)**。差异可观测: 林版下"指定目标"阶段就排除贾诩, 国-标版下诸如流离转移到贾诩身上仍会先成为目标。详见 L3 裁定 |
| 祸首 / 巨象 | 1V1 (`shu.md:408` / `:458`) | 两将的 1V1 版都换成了**蛮裔**("当你登场时，你可以视为使用【南蛮入侵】；【南蛮入侵】对你无效") | 蛮裔是**另一个技能**, 不在本批 18 技范围内, 不接入; 取通用版的 祸首/巨象 |
| 英魂 | 1V1 (`wu.md:283`) | 把"一名其他角色"写死成"对手" | 取通用版, 目标经座席解析; 1v1 中候选恒为对手, 两版等价 |
| 烈刃 | 1V1 (`shu.md:462`) | 把"目标角色"写死成"对手" | 同上 |
| 放逐 | 国-标 (`wei.md:359`) | 结果是"其**叠置**"而非"其**翻面**" (国战的叠置/明置体系) | 取通用版 (翻面) —— 本仓无国战叠置体系 |
| 董卓 | 国-势 (`neutral.md:189`) | 整套技能换成 横征/暴凌 | 不在本批范围, 不接入 |

### spec 提取的两个坑 (如实记录)

1. **曹丕 (林) 条目下没有技能正文**。`wei.md:345` 的「体力上限3（林）Sonia Tang
   WEI 014」条目正文为空, 行殇/放逐/颂威 三条挂在紧随其后的
   「体力上限3（铜雀台）」条目 (`:347-353`) 下 —— 镜像把同一张武将牌的不同
   画作条目并列, 技能文本只在其中一个条目下出现。按"同一武将牌的技能文本"
   取 `:349/:351/:353`, 与 (国-标) 条目 `:357/:359` 逐字比对确认一致 (仅放逐
   末句 翻面/叠置 之差, 见上表)。
2. **贾诩有两张不同的武将牌**。`neutral.md:195`「冷酷的毒士（林）」= 本批对象
   (完杀/乱武/帷幕); `wei.md:607`「算无遗策」是 **SP 贾诩**, 技能为 缜略/间书/
   拥嫡, 本仓已有独立条目 `sp_jiaxu`, 与本批无关。同名不同将, 提取时须按
   **标题行**而非技能名定位。
